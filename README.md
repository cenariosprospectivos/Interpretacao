# Interpretação de Cenários — MD 2036

Ferramenta pedagógica para transformar cenários salvos em consequências estratégicas e medidas de resposta.

## O que a ferramenta faz

- Carrega os cenários salvos do módulo `Cenarios`;
- mostra consequências associadas;
- mostra medidas pré-ativas e pró-ativas;
- gera uma síntese interpretativa;
- exporta JSON e CSV.

## Publicação no GitHub Pages

Crie um repositório chamado `Interpretacao` e envie os arquivos:

```text
index.html
css/
js/
README.md
```

Depois ative:

```text
Settings → Pages → Deploy from a branch → main → /root
```

Link esperado:

```text
https://cenariosprospectivos.github.io/Interpretacao/
```

## Observação

Os exemplos são pré-preenchidos para apoiar o storytelling do curso. Eles podem ser ajustados futuramente pela base do Supabase.
